# Templates para criar skills locais

[Início](../README.md) · [Guia de adaptação](../docs/adaptacao.md)

Estes arquivos são contratos documentais para a pessoa e seu agente criarem skills contextualizadas. Eles não incluem código, conectores nem configuração pronta. Campos entre colchetes precisam de informação confirmada; a implementação usa o formato de skill suportado pelo runtime escolhido.

| Template | Resultado da customização |
|---|---|
| [Preparar a reunião](preparar-reuniao.md) | Uma skill que lê fontes e critérios reais e prepara pauta rastreável. |
| [Gerar fotografia](gerar-fotografia.md) | Uma skill que produz a visão consultável com operador, procedência e lacunas. |
| [Processar reunião](processar-reuniao.md) | Uma skill que interpreta encaminhamentos com operador e atualiza fontes segundo mandato. |
| [Registro de adoção](registro-de-adocao.md) | Uma descrição local da base usada, práticas e diferenças, incluindo adoção parcial. |

Use o guia de adaptação para preencher fontes, consultas, identificação dos itens, critérios, mandatos e verificação. Aproveite capacidades existentes antes de criar outra skill equivalente. Instale e teste no ambiente local.

As três funções podem ser distribuídas juntas, por exemplo num plugin. Sua versão de implementação permanece distinta da versão de cada template e da edição do protocolo. Quando copiar um template, preserve sua identificação e a procedência prevista na licença, conforme os arquivos de release.
